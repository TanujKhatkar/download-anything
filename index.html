Install

Two minutes, one time

You need both parts: the extension (the interface) and the engine (the downloader). Both are in the zip.

Download and unzip the package

Grab download-anything-1.0.0.zip and extract it somewhere you will keep it.

Load the extension

Open chrome://extensions, turn on Developer mode, click Load unpacked and choose the extension folder. Pin the icon.

Start the engine

Open the engine folder and double-click Start Download Engine.bat (Windows) or Start Download Engine.command (macOS). First run installs its own components — it needs Python 3.

Paste, pick, done

Click the icon, press Paste, choose a quality. The file lands in your Downloads folder.

Heads up: the extension needs the engine running on the same computer. That is deliberate — it is what keeps your links and files off any server. If the engine is not running, the popup tells you exactly how to start it.

Questions

Good to know

Why does the extension need a separate engine?

Browsers cannot fetch video from sites like YouTube or Instagram — the streams are signed, expire quickly, and are blocked by cross-origin rules. Those pages have to be read and the stream decoded outside the browser. The engine does that on your computer, so nothing passes through a server.

Does it work on Netflix, Prime Video or Disney+?

No. Those use DRM and cannot be downloaded by any tool — including this one. The same goes for paid Spotify.

Where do my downloads go?

Into your normal Downloads folder, saved by Chrome itself. The extension has no access to your existing files.

Is anything uploaded anywhere?

No. There is no account, no analytics, no tracking and no server operated by this project. The only stored setting is whether “Use browser cookies” is on, and it stays on your device.

A download fails after a site update. What do I do?

Update the engine. Open a terminal and run python -m pip install -U yt-dlp, then restart the engine. Site changes are fixed there within days.

Is this legal to use?

Use it only for content you own or have the right to save, and respect each site's terms of service and copyright law. The tool is neutral; your use is what matters.
